# Emily Tuttle — The Sports Issue

A static, GitHub Pages-ready portfolio website.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder directly into the repository. Keep the `assets` folder with the HTML files.
3. In the repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will display the published site address after deployment.

## Add another story later

1. Duplicate either `rivets.html` or `sidelining-sundays.html`.
2. Rename the copy to a short URL filename, such as `speaking.html`.
3. Update the text, image path, and page title in that file.
4. Add a matching link in the navigation and the homepage story picker in `index.html`.

## Images

All current images are inside `assets/images`. To replace an image, place the new file in that folder and update the relevant `src="assets/images/..."` path.
